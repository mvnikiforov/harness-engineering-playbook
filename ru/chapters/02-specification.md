# Спецификация: выравнивание намерений с агентом

Режим Vibe Coding отлично справляется с требованиями, которые помещаются в один рабочий вечер. Но как только проект требует длительных итераций, диалоговый формат Vibe Coding превращается в узкое место для выравнивания намерений (Intent Alignment).

Эта глава посвящена построению механизмов согласования намерений. Мы начнем с диагностики причин, по которым Vibe Coding перестает работать, затем заложим методологическую основу — послойную организацию информации и структурированные измерения, — после чего покажем, как на базе этой структуры итеративно создавать спецификацию, готовую к выполнению агентом. В завершение мы свяжем все элементы воедино на примере рабочего процесса реального проекта.
